# 音声認識テスト用Webアプリケーション (PWA)

Web Speech API（`SpeechRecognition` / `webkitSpeechRecognition`）を活用し、指定された特定キーワードの音声認識成否をリアルタイムで検証・テストする単一ファイルWebアプリケーションです。

---

## 主な機能と特徴

1. **単一ファイル完結設計 (`index.html`)**
   - 外部ライブラリ（CDN等）への依存ゼロ。HTML、CSS、JavaScript、PWAマニフェスト、SVGアプリアイコン、Web Audio効果音生成までを1つのHTMLファイル内に完全内包。
2. **iOS Safari (14.5+) 完全対応**
   - `webkitSpeechRecognition` に対応。
   - iOS Safari特有の「無音時の自動切断」に対応する「自動再接続ループ機構（バックオフ制御付き）」を搭載。
   - 画面タップによるオーディオコンテキストと音声認識の安全なユーザーアンロック。
3. **高精度な表記ゆれ・正規化ロジック**
   - 全角・半角数字の統一（`１` ↔ `1`）
   - 大文字・小文字、特殊空白、句読点の除去
   - アルファベット・カタカナ表記ゆれ（`1kg`, `1k`, `いちきろ`, `一キロ` 等）
   - 小数点・漢数字表記ゆれ（`0.5キロ`, `0.5kg`, `０．５`, `コンマ5`, `点5`, `零点五`, `れいてんご`, `半キロ` 等）
   - 「1キロ」判定時に「0.5キロ」の「5」や「15キロ」等の誤検知を防止する厳格な境界チェック。
4. **ダッシュボードUI / UX**
   - 筋トレ・フィットネス等の特定用語を排除した、純粋な音声認識ベンチマーク用ダッシュボード。
   - モバイル縦画面（セーフエリア対応）に最適化されたダークテーマUI。
   - 稼働状態インジケーター（マイク波形アニメーション & ステータスドット）。
   - リアルタイム文字起こし（確定結果 & 中間結果 `interimResults`）。
   - 検知成功時のエメラルドグリーンハイライト、達成度バッジ（例: `3 / 7 達成 (43%)`）、検知時刻＆一致発話の表示。
   - Web Audio APIによる検知チャイム音（ミュート切替可能）。
   - タイムスタンプ付きのデバッグログコンソール（クリア & コピー機能）。
   - 手動テキスト判定シミュレーター（マイクを使わずに判定ロジックの動作を確認可能）。

## 起動・テスト手順

### 1. ローカルPCでのテスト (Chrome / Edge 等)

PowerShellまたはコマンドプロンプトで本ディレクトリを開き、Pythonの簡易サーバーを起動します：

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開き、「音声認識スタート」をクリックしてマイクを許可してください。

### 2. iPhone (iOS Safari) でのテスト手順

> **重要**: Web Speech API（`SpeechRecognition`）は、ブラウザのセキュリティポリシーにより**HTTPS接続**または**localhost**環境でのみ動作します。ローカルネットワークのIP（`http://192.168.x.x:8000`）経由の非暗号化HTTP接続ではマイクや認識APIが制限されます。

iPhoneでテストする場合は以下のいずれかの方法を推奨します：

#### 方法A: ngrok を使用してHTTPSトンネルを作成（最も簡単）
```bash
# ターミナル1でローカルサーバー起動
python -m http.server 8000

# ターミナル2でngrok起動
ngrok http 8000
```
発行された `https://xxxx.ngrok-free.app` にiPhoneのSafariでアクセスします。

#### 方法B: Macと有線接続してSafari Webインスペクタでデバッグ
MacとiPhoneをUSB接続し、Safariの開発メニューからローカルポート転送またはデバッグが可能です。
